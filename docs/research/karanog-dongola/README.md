## Publication limits

No Arabic draft or actual image assets were supplied. Bilingual consistency, image-file identity and commissioning rights therefore remain unchecked. All nine image positions and original paths are retained as inactive comments in the revised article; the cover path is inactive too. Corrected captions and precise activation requirements are in the image audit. The text remains `draft: true`.

The research is complete within those inputs; these are clearly identified publication dependencies, not evidence that a commission or permission never existed. No files were merged into a repository and nothing was published. The CSVs use UTF-8 with a BOM for spreadsheet compatibility; Markdown files use UTF-8.
